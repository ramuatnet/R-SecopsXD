# Engine Protocol v1 (rsec-engine)

Language-agnostic contract between the TS control plane and the scan engine
data plane. Transport: **newline-delimited JSON over stdio** (one object per
line; no embedded newlines inside an object). TCP variant reserved for v2.

## Envelope

Request:

```json
{
  "id": "uuid",
  "method": "http.get",
  "params": {
    "scan_id": "uuid",
    "action_id": "uuid",
    "scope": { "origins": ["https://t.example"], "allow_public": false, "max_redirect_hops": 5 },
    "budget": { "max_requests": 500, "max_ms": 60000 },
    "safety": { "rate_per_sec": 10, "burst": 20, "max_concurrency": 8 },
    "args": { "url": "https://t.example/login" }
  }
}
```

Response (one per request, same `id`):

```json
{
  "id": "uuid",
  "result": {
    "status": 200,
    "headers": { "server": "nginx" },
    "body": "…capped to 256 KiB…",
    "final_url": "https://t.example/",
    "elapsed_ms": 42,
    "truncated": false,
    "redirect_chain": ["https://t.example/a"],
    "evidence_ref": null
  }
}
```

Error response:

```json
{ "id": "uuid", "error": { "code": "scope_blocked", "message": "out-of-scope request blocked: …" } }
```

Error codes: `scope_blocked`, `safety_blocked`, `budget_exhausted`, `bad_request`, `internal`.

## Methods (v1)

| Method | Params.args | Result | Notes |
|---|---|---|---|
| `ping` | — | `{ pong: true, engine, version }` | liveness + handshake |
| `http.get` | `{ url, headers? }` | status/headers/body/final_url | manual redirects, every hop scope-checked |
| `http.post` | `{ url, headers?, body, content_type? }` | same | body ≤ 8 KiB (platform probe limit) |
| `recon` | `{}` | `{ headers, robots, tech }` | passive observation of the origin root |
| `shutdown` | — | `{ ok: true }` then exit 0 | graceful |

v1 intentionally excludes: `fuzz.variants`, `replay`, `verify`, `oob.*`, `tls`,
`cloud.*`, raw sockets (they arrive with the Phase 4 expansion; the protocol
version bumps to v2 when their schemas freeze).

## Invariants carried by every implementation (I1–I10 subset)

1. Scope: scheme+host+port must match one of `scope.origins`; **every redirect
   hop** is re-validated; out-of-scope → `scope_blocked` error (never followed).
2. Safety: token-bucket rate limit, concurrency cap, request timeout.
3. Redaction: Authorization/Cookie/Set-Cookie headers and known secret patterns
   in body excerpts are redacted before leaving the engine.
4. Bodies capped at 256 KiB; `truncated` flag set.
5. `budget.max_requests` is enforced across the whole engine lifetime.
